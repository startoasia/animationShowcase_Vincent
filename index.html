待機中
🎆
滑動觸發全畫面灑花已啟用！ 上下滑動頁面讓此區塊進出視窗，即會觸發全畫面彩帶雨。
對應 js/config.js 設定：preset: "confetti", mode: "burst", trigger: { type: "scroll", selector: "#confetti-scroll-zone", once: false }

🎉 雙側禮炮 (Confetti Cannon)

左下 45° + 右下 135° 向中央噴射禮炮，支援替換噴射物的圖片（如金幣）。
